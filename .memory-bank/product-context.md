# Skyvia MCP Server - Product Context

## Project Overview
The Skyvia MCP Server is a Model Context Protocol server that provides tools for interacting with the Skyvia API. It focuses primarily on integration-related endpoints, allowing users to manage workspaces, connections, and integrations through the MCP interface.

## Goals
- Create a fully functional MCP server for Skyvia API
- Deploy the server on Smithery for easy access
- Focus on integration API endpoints
- Provide comprehensive documentation
- Support secure authentication

## Key Features
- Workspace management tools
- Connection management tools
- Integration listing, viewing, and execution tools
- Secure API token handling
- Dockerized deployment
- Smithery integration

## Target Users
- Developers working with Skyvia
- AI assistants needing to interact with Skyvia
- Integration specialists
- Data pipeline engineers

## Technical Requirements
- Python-based implementation
- Docker container for deployment
- Smithery-compatible configuration
- MCP protocol compliance
- Secure token management

## Current Status
- Initial implementation completed
- Core integration API endpoints exposed
- Documentation created
- Deployment configuration prepared
